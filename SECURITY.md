# Security

Send potential vulnerabilities privately to the repository maintainer, preferably through [GitHub private vulnerability reporting](https://github.com/jeremybboy/codex-ableton-bridge/security/advisories/new) when available. Include the version, prerequisites and a minimal synthetic reproduction.

The bridge trusts same-user local processes and runs against the active Live Set. Review the Python source before enabling the Control Surface or registering the MCP server. Use synthetic project data when reporting issues and redact local paths and logs.
